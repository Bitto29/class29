ONE-TIME CONNECTION

Connect Telegram.

Authorize your own Telegram account, choose the class groups, then add the generated values to your private Render environment.

1. Cloud API connection

Enter the Render Web Service URL and the private setup key you configured there. These are not your Telegram or GitHub tokens.

2. Telegram login

Your API ID and API Hash must already be set privately in the Render service environment.

3. Choose your class groups

Select the groups where your classes are posted. Only groups your Telegram account can access are listed.

4. Add these values to Render

The session string is equivalent to a login credential. Never share it, commit it, or paste it into ChatGPT. Copy it directly into Render as TELEGRAM_SESSION.

In Render, add these values to the existing Class 29 background worker. Also set TELEGRAM_PHONE to the phone number you used. Keep API ID, API Hash and GitHub token in Render environment variables only. Then deploy/restart the worker.
